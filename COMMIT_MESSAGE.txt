feat: Implement folder-based document access control

Implement a comprehensive folder-based access control system for TrustVault that allows owners to grant folder-level access to viewers while maintaining fine-grained document-level access control.

## Key Features

- Owners can create folders and grant/revoke access to viewers
- Viewers granted folder access can see all documents in the folder
- Viewers can only download/view documents they have explicit document-level grants for
- Denied access attempts return HTTP 404 (not 403) to prevent enumeration
- All access attempts (successful and denied) are audited

## Access Control Model

### Folder Grant (Visibility)
When owner grants folder access to viewer:
- Viewer can see all documents in folder
- Viewer cannot download any document (without document grant)
- Folder view shows document access status (✓ or ✗)

### Document Grant (Access)
- Owner maintains document-level grants (READ/EDIT)
- Viewer can download only with explicit document grant
- Document grant works independently of folder grant

### Combined Access
- Viewer sees document if they have folder grant
- Viewer can access document if they have:
  - Explicit document grant (READ or EDIT), OR
  - Folder grant AND document grant

### Denied Access
- Denied access returns HTTP 404 (prevents enumeration)
- No content in response (no information leakage)
- Separate 403 Forbidden for folder-level denial

## Security Properties

✅ No Anonymous Access: All operations require authentication
✅ No Privilege Escalation: Viewer cannot become owner
✅ No Data Leakage: Denied access returns 404
✅ No Enumeration: Cannot determine if document exists
✅ No Bypass: Folder grant doesn't grant document access
✅ Immutable History: Audit trail cannot be deleted
✅ Atomic Operations: Transactions ensure consistency
✅ Role-Based: Different capabilities for OWNER vs VIEWER

## Audit Trail

All access attempts logged:
- Successful operations: recordSuccess()
- Denied operations: recordDenied()
- Separate REQUIRES_NEW transaction
- Includes: actor, action, documentId, timestamp, details
