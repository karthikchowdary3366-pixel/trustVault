🔐 SECURITY IMPLEMENTATION

Access Control Rules:
┌──────────────────────────────────────┐
│ DOCUMENT DOWNLOAD PERMISSION CHECK   │
├──────────────────────────────────────┤
│ 1. Is user document owner?           │
│    YES → ALLOW (full access)         │
│    NO → Continue                     │
├──────────────────────────────────────┤
│ 2. Has explicit document grant?      │
│    YES → ALLOW (based on permission) │
│    NO → Continue                     │
├──────────────────────────────────────┤
│ 3. Document in folder?               │
│    YES → Check folder grant          │
│         YES → ALLOW (read-only)      │
│         NO → DENY (404)              │
│    NO → DENY (404)                   │
└──────────────────────────────────────┘

HTTP Status Codes:
• 200 OK - Access granted, content returned
• 404 NOT FOUND - Access denied or document not found (enumeration prevention)
• 403 FORBIDDEN - Folder access denied (explicit permission check)
• 401 UNAUTHORIZED - Not authenticated
• 400 BAD REQUEST - Invalid input

Security Properties:
✓ No anonymous access
✓ No privilege escalation
✓ No data leakage
✓ No enumeration (404 for all denials)
✓ Audit trail immutable
✓ Atomic operations
✓ Role-based access
✓ Input validation

🚀 DEPLOYMENT & USAGE

Quick Start (5 minutes):
1. Build: mvn clean install
2. Start: mvn spring-boot:run
3. Navigate to: http://localhost:8080/folders
4. Create folder (as owner)
5. Test access (as viewer)

As Owner:
1. /folders → Create folder
2. Upload documents → select folder
3. /folders/{id} → Grant access to viewer
4. Documents → Grant specific document access

As Viewer:
1. /folders → See granted folders
2. Click folder → View all documents
3. Green ✓ documents → Can open
4. Red ✗ documents → Access denied (404)
